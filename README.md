# Financial Markets Research Platform

A Python-based quantitative finance research project designed to collect, analyse and model financial market data.

## Project Overview

The platform is being developed incrementally, from financial data analysis towards a reproducible research system with databases, machine learning and automated workflows.

## Current Features

- Historical ETF price analysis
- Daily and annualised returns
- Volatility and correlation analysis
- Portfolio risk and return calculations
- Sharpe ratio, CAGR and maximum drawdown
- Portfolio performance visualisations
- Automated unit testing using pytest

## Assets Analysed

SPY, QQQ, IWM, TLT and GLD.

## Technologies

Python, pandas, NumPy, Matplotlib, yfinance, pytest and Git.

## Project Structure

- `market_analysis.ipynb` — Exploratory financial analysis
- `functions.py` — Reusable quantitative calculations
- `tests/test_functions.py` — Automated unit tests
- `data/raw/etf_prices.csv` — Historical ETF data

## Roadmap

- **Version 1:** Python analytics and reproducibility
- **Version 2:** SQL databases and APIs
- **Version 3:** Machine learning and out-of-sample testing
- **Version 4:** Automation and reproducible pipelines
- **Version 5:** PySpark and Databricks
